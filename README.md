# Expense & Budget Visualizer

Aplikasi Coding Camp batch 9 November 2026 untuk mencatat pengeluaran, melihat pembagian kategori, dan memantau batas belanja. Transaksi dan preferensi tersimpan di browser yang digunakan.

## Jalankan secara lokal

Dari folder proyek, jalankan `python3 -m http.server 8000`, lalu buka [localhost:8000](http://localhost:8000). Koneksi internet diperlukan untuk memuat Chart.js dari CDN.

## Publikasi dan pengumpulan

1. Buka repository Coding Camp yang sudah ada di GitHub Desktop. Salin `index.html`, `css/`, `js/`, `.kiro/`, dan `README.md` dari workspace ini ke folder repository tersebut. Di Finder, tekan **Command + Shift + .** untuk menampilkan `.kiro`.
2. Periksa nama repository tujuan. Nama yang diminta adalah `CodingCamp-9November26-hasan`, sedangkan remote yang ditemukan menggunakan `CodingCamp-9November26-mhasanalhakim`. Gunakan nama yang sesuai dengan ketentuan pengumpulan Anda.
3. Di GitHub Desktop, periksa daftar perubahan, pastikan `.kiro` ikut, lalu commit ke `main` dan klik **Push origin** atau **Publish repository** sesuai keadaan repository.
4. Di GitHub, buka **Settings → Pages**. Pilih **Deploy from a branch**, cabang **main**, dan folder **/(root)**, lalu klik **Save**. [Panduan GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
5. Buka **Visit site** setelah deployment selesai. Coba tambah transaksi, muat ulang halaman untuk memeriksa penyimpanan, lalu hapus transaksi uji.
6. Siapkan **AWS Builder ID**, **URL repository GitHub**, dan **URL GitHub Pages** untuk formulir pengumpulan.
